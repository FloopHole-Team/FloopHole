# Changelog

The first version heading below is the version used when compiling FloopHole.

## [1.2.0]

- Load and save plugin presets from the main toolbar.
- Show version information and the repository link in the About window.
- Support clipboard shortcuts in the native Notebook and Edison editors.

## [1.1.1]

- Fixed Fruity Notebook and Fruity Notebook 2 for MacOS

## [1.1.0]

- Newly added: Newtone, Newtime, Edison effects
- Preset picker fixes (redundant categories, type-to-search, scrollbar thumb scrolling)
- Fixed hover help on MacOs

## [1.0.0]

- Bridge FL Studio native instruments and effects on macOS and Windows.
